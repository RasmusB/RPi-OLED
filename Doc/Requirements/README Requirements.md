# README Requirements

## Naming and versioning

The requirements document shall be named as:

`[Project Name] Requirements v1.0.0`

The version in the filename indicates the version of the document itself and does not necessarily track the release tags, but there is some correlation:

- The **major** part increases when there are changes that force a new major release of the board.
- The **minor** part is updated for most other changes - new requirements, changed acceptance criteria etc.
- The **subrevision** is updated for any changes that don't affect the technical requirements or implementation. This can include (but is not limited to) spelling and formatting.

All requirements shall be numbered according to their category. A number is never reused - if a specific requirement becomes obsolete, it is instead marked as such.
