# README Errata

This folder is used to track any errata and/or deviations in the design.

This could be designs that fail to meet the requirements, conditions that have been observed to cause catastrophic failure, or anything else that might show up.

This is also where differences between production files and delivered boards are documented, such as MPN substitutions made by the manufacturer made - even if they haven't caused any issues.

Not every revision or patch note will have an errata.

## Example folder content

```text
.
└── [Project name]
    └── Doc
        └── Errata
            ├── [Project name] v1.0.0 Errata.md
            ├── [Project name] v1.1.0 Errata.md
            ├── [Project name] v1.2.1 Errata.md
            └── ...
```
