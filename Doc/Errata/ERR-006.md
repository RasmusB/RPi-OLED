# ERR-006: EEPROM is permanently write protected

In the schematic, JP1 shows an open solder jumper. But the wrong footprint was used, so it is really connected, pulling the WP pin into the write protected state.

## Cause

Human error.

## Patch

Cut the JP1 solder jumper.

## Fix

Switch to the correct footprint.
