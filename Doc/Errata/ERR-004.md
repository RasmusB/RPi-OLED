# ERR-004: OLED footprint has wrong pinout

Pins 27 and 28 does not match the polarity that the other DSI signal pairs has. In the schematic, the polarity was reversed anyway, so the error canceled itself out.

## Cause

Error in the (preliminary) datasheet used during development.

## Fix

Fix the footprint before using it in another board.
