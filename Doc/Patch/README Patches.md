# README Patches

New patch notes are created with the following file name pattern:

`[Project Name] [Tag] Patches.md`

Where `[Project Name]` is the name of the repository, and `[Tag]` is the version number of the board *after* applying the patch, i.e. `v1.2.3`. There should never be a 'patch 0', since that is reserved for release packages.

## Example content

```text
.
└── [Project name]
    └── Doc
        └── Patch
            ├── [Project name] v1.0.1 Patch.md
            ├── [Project name] v1.1.1 Patch.md
            ├── [Project name] v1.2.1 Patch.md
            └── ...
```
